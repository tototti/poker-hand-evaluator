# ポーカー役判定プログラム 仕様書

## 1. 概要

トランプ5枚の組み合わせを受け取り、ポーカーの役（役の種類とランク）を判定するPythonプログラム。
コマンドラインからは2つのhand（各5枚）を受け取り、それぞれの役と勝敗を出力する。

## 2. 対象範囲

- 標準的な52枚のトランプを使用したポーカー役判定
- 2つのhandはそれぞれ独立に扱い、hand間で同じカードが重複することを許容する
- 役の判定と、同じ役同士を比較するための強さ（ランク）の算出
- 2つのhandの比較による勝敗判定
- 対応入力枚数: 1handあたり5枚固定 

## 3. カードの表現

### 3.1 スート（絵柄）

| 記号 | 意味 |
|------|------|
| S | スペード (Spade) |
| H | ハート (Heart) |
| D | ダイヤ (Diamond) |
| C | クラブ (Club) |

### 3.2 ランク（数字）

| 記号 | 意味 | 数値 |
|------|------|------|
| 2〜9 | 数字カード | 2〜9 |
| T | 10 | 10 |
| J | ジャック | 11 |
| Q | クイーン | 12 |
| K | キング | 13 |
| A | エース | 14（ただしA-2-3-4-5のストレートでは1として扱う） |

### 3.3 カードの表記形式

`"<ランク><スート>"` の2文字文字列で表現する。

例: `"AS"`（スペードのエース）, `"TD"`（ダイヤの10）, `"9H"`（ハートの9）

## 4. 役の一覧（強い順）

| No | 役名（日本語） | 役名（英語） | 判定条件 |
|----|---------------|-------------|----------|
| 10 | ロイヤルストレートフラッシュ | Royal Flush | 同スートでA-K-Q-J-Tの連番 |
| 9 | ストレートフラッシュ | Straight Flush | 同スートで5枚連番 |
| 8 | フォーカード | Four of a Kind | 同ランク4枚 |
| 7 | フルハウス | Full House | 同ランク3枚 + 同ランク2枚 |
| 6 | フラッシュ | Flush | 同スート5枚（連番でない） |
| 5 | ストレート | Straight | 5枚連番かつ同スートでない |
| 4 | スリーカード | Three of a Kind | 同ランク3枚 |
| 3 | ツーペア | Two Pair | 同ランク2枚の組が2組 |
| 2 | ワンペア | One Pair | 同ランク2枚の組が1組 |
| 1 | ハイカード | High Card | 上記いずれにも該当しない |

複数の役の条件を満たす場合は、Noの値が高い役を優先する。

## 5. 役の強さ比較仕様

同じ役同士が複数プレイヤー間で発生した場合に優劣を決定できるよう、各役ごとに比較に必要なキー情報（タイブレーカー）を算出すること。

タイブレーカーは、左に書いたキーから順に比較し、最初に差がついた時点で優劣を決定する。

| 役 | タイブレーカー（比較順） |
|----|------------------------|
| ロイヤルストレートフラッシュ | なし（常に同値。必ず引き分けとなる） |
| ストレートフラッシュ | 連番の最高位ランク |
| フォーカード | 4枚組のランク → キッカー1枚のランク |
| フルハウス | 3枚組のランク → 2枚組のランク |
| フラッシュ | 5枚のランクを降順に並べ、上位から順に比較 |
| ストレート | 連番の最高位ランク |
| スリーカード | 3枚組のランク → 残り2枚のランクを降順に並べ、上位から順に比較 |
| ツーペア | 高い方のペアのランク → 低い方のペアのランク → キッカー1枚のランク |
| ワンペア | ペアのランク → 残り3枚のランクを降順に並べ、上位から順に比較 |
| ハイカード | 5枚のランクを降順に並べ、上位から順に比較 |

* スートは強さに影響しない
* ストレートおよびストレートフラッシュにおける A-2-3-4-5 の最高位は「5」として扱う（「6. 判定ロジックの補足」2 に準拠）
* 上記のキーがすべて一致した場合は同値（引き分け）とする

## 6. 判定ロジックの補足

1. **入力検証**
   - 枚数チェック（5枚固定）
   - 重複カードのチェック（5枚セット内に、同じカードが2枚以上存在しないこと. hand1, hand2間では重複は可能.）
   - ランク・スート文字の妥当性チェック

2. **ストレート判定の特殊ケース**
   - A-2-3-4-5はストレートとして扱う
   - この場合、タイブレーカーの最高位は「5」として扱う（Aは1扱い）

3. **ストレートフラッシュ判定**
   - ストレートフラッシュのうち最高位がA（A-K-Q-J-T）であればロイヤルストレートフラッシュ


## 7. 入出力

### 7.1 実行ファイル

* 実行ファイル名は `python_poker.py` とする。
* コマンドラインから実行できるようにする。

### 7.2 入力

* コマンドライン引数として、**2つの hand（それぞれ5枚のカード）** を渡す。
* 1つの hand は、5枚分のカード文字列をカンマ区切りで並べた1つの引数として表現する（例: `"AS, KS, QS, JS, TS"`）。
  * カンマの前後の空白は無視する。
  * 小文字での入力も可能(小文字が含まれていた場合、大文字に変換して扱う)
* 第1引数を hand 1、第2引数を hand 2 とする。

```
python python_poker.py "<hand1のカード5枚>" "<hand2のカード5枚>"
```

実行例:

```
python python_poker.py "AS, KS, QS, JS, TS" "9H, 9D, 9C, 2S, 2H"
```

### 7.3 出力

* 標準出力に、以下の3行を出力する。
  1. hand 1 のカードと役名
  2. hand 2 のカードと役名
  3. 勝敗の結果

* 出力フォーマット:

```
Hand 1: <カード5枚> => <役名（英語）>
Hand 2: <カード5枚> => <役名（英語）>
Winner: Hand 1 / Hand 2 / Draw
```

* 役名は「4. 役の一覧」の英語名（例: `Royal Flush`, `Full House`, `High Card`）を用いる。
* カードは入力で与えられた順序をそのまま、`, ` 区切りで表示する。
* カードの表記は常に大文字に正規化して表示する（小文字で入力された場合も大文字で出力する）。

出力例:

```
Hand 1: AS, KS, QS, JS, TS => Royal Flush
Hand 2: 9H, 9D, 9C, 2S, 2H => Full House
Winner: Hand 1
```

### 7.4 勝敗判定

* まず役の強さ（「4. 役の一覧」の No が大きいほど強い）で比較する。
* 役が同じ場合は「5. 役の強さ比較仕様」のタイブレーカーで比較する。
* 役もタイブレーカーも完全に一致する場合は引き分けとし、`Winner: Draw` を出力する。

### 7.5 終了ステータス

| ケース | 終了ステータス |
|--------|---------------|
| 正常終了 | 0 |
| 入力エラー（引数の数、カードの不正など） | 1（標準エラー出力にエラーメッセージを出力） |

## 8. エラーハンドリング方針

| ケース | 挙動 |
|--------|------|
| 引数が2つでない | `ValueError` を送出（使い方を標準エラー出力に表示） |
| hand が5枚でない | `ValueError` を送出 |
| hand 内に重複カードがある | `ValueError` を送出（hand をまたぐ重複はエラーとしない） |
| 不正なランク／スート文字 | `ValueError` を送出（Cardの生成時点で検証） |

* コマンドライン実行時は、送出された `ValueError` を捕捉してエラーメッセージを標準エラー出力に表示し、終了ステータス 1 で終了する。
